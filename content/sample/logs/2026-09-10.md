First deploy to GitHub Pages. With `Settings > Pages > Source: GitHub Actions`, every push to `main` runs the workflow and publishes.

- `.nojekyll` is required so files starting with `_` are not ignored
- Routes are real paths (`/p/...`); `404.html` sends unknown paths back to the app so a refresh on a sub-route still works
- After deploying, compare `npm run check` with the live page once

Short, frequent log entries work best. One file per date.
