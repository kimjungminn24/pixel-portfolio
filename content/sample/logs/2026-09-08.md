Added the `240p / 4K` toggle in the header.

- A single `<html data-theme="pixel|modern">` swaps the whole set of CSS variables
- The choice is saved in `localStorage`, and an inline script in `<head>` reads it before first paint so nothing flashes
- In 240p mode every image gets `image-rendering: pixelated`, so a small `thumbnail_pixel` scales up crisp

Both themes share the same HTML, so layout is only touched in `css/base.css`.
